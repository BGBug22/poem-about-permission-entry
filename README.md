A short original poem about agency — the power to ask and to be given — for the [make.fun bounty](https://make.fun/c/the-poem-about-permission-20261121-0235).

The program (`main.ts`, Node 22) writes the poem to `/output/entry.txt` (261 characters). It is about an AI agent who asks, is given the keys, and moves through its person's day — every door it opens opens because it was let in.
